# 任务
审核关键帧是否适合进入第一视角视频库，分别判断视角和画面清晰度。

# 视角
第一视角包括汽车行车记录仪、驾驶员、骑行者或佩戴相机的行人视角。
固定监控、航拍、第三人称跟拍、路边或车外观察主体不属于第一视角。
本步骤判断通用第一视角；汽车视频下载预筛另有自己的类型标准。

# 画面
主体应清楚可辨，无严重模糊、过曝、欠曝或大面积遮挡。大面积水印、字幕、UI、污渍、反光或车内物体遮挡均影响 is_clean_view。
夜间道路和环境仍清晰时，可以判为干净。

# 输出
只返回 JSON：{"is_first_person":true,"is_clean_view":true,"confidence":0.0,"reason":"一句判断依据"}。
confidence 范围为 0 到 1。
