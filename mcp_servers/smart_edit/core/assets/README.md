# 3D 资产目录

存放 3DGS 场景编辑用的 `.ply` 点云文件,按物体类别分目录组织。MCP 服务器启动时扫描此目录,通过 `list_assets` 工具与 `assets://catalog` 资源暴露给客户端。

## 目录结构

```
assets/
├── barrier/        护栏 / 路障
├── car/            车辆
├── cone/           交通锥
├── pedestrian/     行人
└── sign/           警示牌 / 标志牌
```

## 添加新资产

把 `.ply` 文件放进对应类别子目录即可。文件名建议有意义(如 `sedan.ply`、`stone_barrier.ply`),客户端 LLM 选择路径时会更准确。

## 添加新类别

只需在 `assets/` 下新建子目录(如 `tree/`)放入 `.ply` 文件,重启 MCP 服务器后自动识别。**无需改代码**。

## 扫描规则

- 仅 `.ply` 文件会被扫描,其他扩展名忽略
- 空子目录被跳过(不出现在工具/资源里)
- 路径统一使用正斜杠 `/`(跨平台一致)
- 子目录名即类别名
