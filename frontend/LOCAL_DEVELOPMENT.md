# 个人前端开发

个人前端分支单独保存界面和 Node 服务代码，不随公共后端分支提交 MR。独立 Git 工作目录避免多人覆盖同一份 `app.js` / `server.mjs`；各自使用独立端口和终端进程。

只开发界面、复用现有后端环境和日志时，在个人工作目录的 `frontend` 下启动，例如：

```bash
cd /你的工作目录/frontend
HOST=127.0.0.1 PORT=5174 \
ADAGENT_PROJECT_ROOT=/现有后端项目目录 \
node server.mjs
```

`ADAGENT_PROJECT_ROOT` 指向包含现有 `configs/`、`environments/`、`logs/`、数据及工具的目录。静态页面从当前 `frontend` 工作目录读取，Agent 子进程使用所选后端项目。端口 5174 与原服务 5173 分开；创建工作目录不会自动启动或重启服务。

这种模式共用后端模型配置、运行历史和任务。配置面板保存和启动/停止任务都会作用于所选后端项目；界面代码的 Git 隔离不会自动隔离这些数据。需要独立后端实验时，应准备自己的环境、部署配置和运行目录，再改用对应项目路径。

前端代码中保留了续跑、子 Agent 活动和图片预览的独立模块，当前入口尚未全部接通。历史记录、配置加载和接口路径已有测试；后续修改这些功能时仍需验证实际页面和 HTTP 接线。

公共后端更新合入主分支后，可将主分支合入个人分支，继续保留界面修改。后端修复另建公共分支提交，避免把个人前端提交带入后端 MR。
