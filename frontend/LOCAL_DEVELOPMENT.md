# ly 的独立项目目录

在 `/inspire/hdd3/project/intelligent-driving-agent/public/workspace/ly/adagent` 开发整个项目，使用本仓库的 `ly` 分支。这里是独立 Git 仓库，修改源码、提交和切换分支都不会改变原项目目录。

前后端改动分别提交；公共后端 MR 只挑选对应提交，不直接把整个个人分支合入。模型和本机部署配置继续留在本地，密钥保存在被忽略的 `.env`。

环境、基础数据、检索视频与索引通过链接复用现有资源；修改这些共享资源仍会影响其他使用者。日志、输出、前端缓存和服务任务目录独立保存。

需要启动个人前端时，在本目录执行（需 Node.js）：

```bash
PORT=5174 bash scripts/start_frontend.sh
```

访问本机或 VSCode 转发后的 5174 端口。启动脚本会绑定本项目根目录；直接从 `frontend` 目录运行 `node server.mjs` 时，服务也默认使用本项目，而不是原来的 ghc 项目。

旧日志和实验产物保留在原项目，可按已有绝对路径查看。

前端已接入对话续跑、子 Agent 活动、图片与视频预览、产物文件和左侧流程跟随。刷新页面会恢复上次选中的运行；从历史打开正在执行的运行，也会恢复停止按钮。停止会终止该运行及其独立工具进程，保留产物，并显示为“已中断”；不会自动重新启动。

在同一对话发送新指令会接续已有上下文，点击“新对话”才会启动独立任务。续跑生成新的运行记录，并保留历史记录。前端服务重启后仍可识别、停止持久化记录中的主进程；实际工具的阶段复用能力由后端决定。

右侧滚动浏览会高亮左侧对应工具。查看旧内容时不强制滚到底部；回到底部后继续跟随新步骤。图片按需加载，视频点击后加载；轨迹图标注为几何检查，不代表相机渲染或策略仿真结果。

视频代理优先使用 `ADAGENT_FFMPEG_BIN` 或 `IMAGEIO_FFMPEG_EXE` 指定的转码器；未指定时自动查找本项目环境中的FFmpeg及系统PATH，不依赖其他用户的固定环境路径。转码结果缓存在 `frontend/.cache/eightcam/`，实验原视频保留。

播放缓存包含源文件版本（大小、纳秒修改时间/变更时间、文件身份）及编码配置，同名MP4被重写后不会继续复用旧缓存。原生07视频写入各轮 `result_dir/videos/`；旧版后端仍写公共debug目录时，发布前先复制归档。历史结果不能直接引用下一轮会覆盖的公共视频路径。


06/07并行运行时，各显示一张独立的工具卡片和任务实际耗时。同一任务的提交与结果取回合并展示，原始调用仍保存在日志中；任务完成后可直接查看实际产物，无需等主Agent再次取回。补充发布到历史记录的视频仍会保留显示。

前端按持久化任务ID恢复状态。即使主Agent已退出，只要后台任务仍在运行，刷新后仍可看到状态和停止按钮；停止会结束该执行作用域的两个分支，不影响其他任务或已完成产物。总耗时按运行墙钟记录，各并行分支耗时可重叠。

05内部现在按顺序显示“准备自车加速历史”和“编辑攻击车”。前者由程序完成，不新增一次模型API调用；后者仍显示候选编辑、VAD自测和图像检查。子阶段开始与结束均记录，刷新可恢复。
