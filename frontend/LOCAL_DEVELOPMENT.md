# 在 ly 分支开发整个项目

日常直接打开原来的 `adagent` 项目目录，在 `ly` 分支修改前端和后端。无需打开 `.worktrees`；之前为本轮创建的两个额外工作目录已经移除。

```bash
git branch --show-current
# ly
```

`ly` 包含已提交的公共后端和个人前端版本。前后端修改分别保存为提交，方便后续只挑选后端提交到公共 MR 分支；不要把整个个人分支直接合入公共后端分支。

同一个项目目录只有一个当前分支。切换分支会影响使用这个目录的全部编辑器和会话；其他人同时修改同一目录时仍需协调。Git 分支保存版本，不会自动隔离同时编辑。

本机模型分配、解释器和库路径等配置继续保留在本地。提交功能代码时明确选择相关文件，排除本机配置、真实密钥、日志、缓存、数据和权重。

前端仍从项目的 `frontend` 目录启动，使用同一套环境、配置、日志和任务。已有服务不需要因为分支名称变化而重启；分支切换也不会自动创建新服务。Node 服务的 `ADAGENT_PROJECT_ROOT` 指定后端项目根目录，静态页面从启动时的当前 `frontend` 目录读取。

前端代码中保留了续跑、子 Agent 活动和图片预览的独立模块，当前入口尚未全部接通。历史记录、配置加载和接口路径已有测试；后续修改这些功能时仍需验证实际页面和 HTTP 接线。
