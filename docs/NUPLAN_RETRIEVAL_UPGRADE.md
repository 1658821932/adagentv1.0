# nuPlan检索升级计划与验收

升级日期：2026-10-29。沿用`hzy/nuplan-retrieval`功能分支和PR #1，保留原有工具4/工具6接口。

## 目标与执行顺序

复用现有300条真实Kimi描述，改善否定、未知观察与组合需求的召回，减少重复API费用和视觉排序等待时间。已依次完成召回、条件核验、缓存/并发、测试和真实检索验收。

## 机制变化

- 分字段加权BM25：可见参与者、已观察交互、道路与自车运动分别计分，`uncertainties`不再作为正向检索证据。支持常见驾驶概念的中英同义词、否定和可能性提示。
- 原始查询、低权重扩展和概念覆盖分别排序并融合，防止大量扩展词盖过用户原话。最多24条组成候选池，去除同场景重复片段、适度增加差异后选4条视觉候选。
- 将用户原始逗号/分号条件直接交给视觉排序逐项检查，关键词扩展不能新增条件。`not_met`、`unknown`或非空`missing_conditions`均使候选不匹配；不再导出被拒绝候选的视频。
- 同时最多3个视觉请求，每个仍只传4帧、宽512。请求总预算仍为4个视觉候选；401/403停止新增分发，已在途请求可能完成，不轮换密钥或模型。
- 新增独立SQLite响应表：关键词缓存1天，视觉判断缓存7天。身份包含原始需求、模型/网关/提示版本、条件策略、视频哈希、片段、采样、描述与标注哈希。召回时仍检查视频和标注身份，缓存不能绕过校验。300条原始描述记录及建库签名保持原样。
- 关键词扩展为可选增强。临时网络或格式错误退回原始查询与本地词典，日志记录原因；认证错误明确失败。回归中验证两种行为，真实验收也观察到格式错误回退成功。

配置见`configs/video_retriever.json`。将`query_cache_ttl_seconds`或`rerank_cache_ttl_seconds`设为0可关闭相应缓存；`query_expansion=false`可关闭在线关键词扩展。

## 边界

本地概念词典是轻量召回辅助，复杂否定范围和未收录表达仍需模型与后续人工评测。描述和视觉解释都是模型观察，不是nuPlan标注真值；检索出的几何/实例清单仍来自原始标注。4帧可能遗漏短暂动作，严格未知条件拒绝也可能增加漏检。当前未新增向量模型、全视频时序动作识别或人工全库标签，不声称支持可靠的碰撞/风险检索。

此次只升级检索和媒体导出，未重新训练ADSceneGraph；原有重建及工具契约测试仍通过。原始数据、标注、数据库、密钥、认证配置、视频和模型继续留在本地。
